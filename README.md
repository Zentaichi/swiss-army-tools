# Swiss Army Tools

A comprehensive collection of developer utilities and tools, all accessible from one convenient web application. Inspired by [DevUtils](https://devutils.com/), Swiss Army Tools aims to provide essential developer tools without the need to search for individual online utilities.

## Project Vision

I wanted an easy-to-access jack-of-all-trades tools so I didn't have to juggle between sets of bookmarked websites specializing in one or so "niche". Thus, this project was born bringing all these essential utilities together in one clean, minimalist interface.

## Features

### Currently Implemented
- **Text Tools** - Transform and analyze text with multiple operations
- **Keyboard Tester** - Test keyboard inputs and key combinations
- **Regex Tester** - Test and debug regular expressions with live matching
- **Date Calculator** - Calculate date differences and add/subtract time periods
- **Microphone Tester** - Test and visualize microphone input levels
- **Gamepad Tester** - Test gamepad buttons and analog sticks

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/swiss-army-tools.git

# Navigate to project directory
cd swiss-army-tools

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Inspiration

This project was inspired by [DevUtils](https://devutils.com/), an excellent all-in-one toolbox for developers. While DevUtils is a native macOS application, Swiss Army Tools aims to provide similar functionality as a web application, making it accessible across all platforms and devices.

## Design Philosophy

- **Minimalist UI** - Clean, distraction-free interface
- **Fast & Responsive** - Instant results with no server round-trips
- **Privacy-First** - All processing happens in your browser
- **No Installation Required** - Access from any modern web browser
